## 🚀 Purpose
- Master core data structures (Arrays, Linked Lists, Trees, Graphs).
- Implement foundational algorithms (Searching, Sorting, Recursion).
- Track my daily coding progress.

## 💻 Tech Stack
- Language: Python / Java / C++ (Choose your language)

## 📂 Repository Structure
The repository is organized by topic:
- `Arrays/` - Array manipulation, sliding window, two-pointer problems.
- `Strings/` - Pattern matching, anagrams, reversals.
- `Sorting/` - Bubble, Selection, Insertion, Merge, and Quick sort.
- `Searching/` - Linear search and Binary search.
